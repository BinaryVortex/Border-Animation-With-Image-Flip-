# Border Animation With Image Flip

Border Animation With Image Flip — a small, elegant demo built with plain HTML and CSS that shows an animated border effect and an image flip on hover.

![Preview](https://raw.githubusercontent.com/BinaryVortex/Border-Animation-With-Image-Flip/main/Screenshot%202024-07-03%20095924.png)

## Demo

- Open `index.html` in your browser (or use a Live Server extension) to see the animation.

## Features

- Pure HTML and CSS (no JavaScript).
- Animated border effect around a card.
- Image flip on hover.
- Simple, easy-to-customize styles in `style.css`.

## Files

- `index.html` — the demo page.
- `style.css` — all styles and animations.
- `img2.jpeg` — example image used in the demo.
- `Screenshot 2024-07-03 095924.png` — preview image shown above.

## Usage

1. Clone the repo:

   git clone https://github.com/BinaryVortex/Border-Animation-With-Image-Flip.git

2. Open `index.html` in your browser or serve the folder with a local web server.

3. To customize the effect, edit `style.css`:
   - Change colors, border sizes, and animation durations.
   - Replace `img2.jpeg` with your own image (keep the same filename or update the HTML reference).

## Customization ideas

- Change the border color and animation timing for different moods.
- Add more cards and grid layout for a gallery.
- Convert the hover flip into a click toggle for touch devices using a small JS enhancement.
